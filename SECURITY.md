# Security policy

## Supported versions

Security fixes apply to the default branch (`development`) and the release
branch (`main`). Use the latest commit on those branches when reporting or
verifying issues.

## Reporting a vulnerability

Please report security issues privately through
[GitHub Security Advisories](https://github.com/likwidmack/likwid-gaic/security/advisories/new)
for this repository.

Do not open a public issue for vulnerabilities, and do not include secrets,
tokens, private documents, model prompts, or generated inventory in any report.

We will acknowledge receipt when we can and coordinate a fix before any public
disclosure.
