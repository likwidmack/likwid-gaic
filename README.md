- Windows 11 with WSL2 Ubuntu

- Docker Desktop with WSL integration
- NVIDIA driver and Docker GPU support

This npm project has no runtime dependencies; npm is a portable task runner.

## Commands

```powershell
npm install
npm run check
npm run repos:status
npm run repos:fetch
npm run inventory
```

`repos:fetch` refreshes remote references without changing working files. `repos:update` fetches both remotes and only fast-forwards from the upstream default branch. It refuses dirty or detached worktrees and never resets, rebases, force-pushes, or deletes work.

Current warning: PrivateGPT and Stable Diffusion appear dirty across many files. Review line endings and preserve intentional changes before `npm run repos:update`.

## GitHub setup

This folder was not a Git repository when inventoried. Create an empty GitHub repository, then:

```powershell
git init
git add README.md package.json package-lock.json config scripts docs .github .gitignore
git commit -m "chore: initialize private AI operations hub"
git branch -M main
git remote add origin git@github.com-lkpc:likwidmack/forkedAI.git
git push -u origin main
```

GitHub account split: `likwidmack` owns this operations hub; `tamaramack` owns the three managed forks. Authentication tokens are account-scoped secrets and must never be committed, printed, or copied between account configurations. Never commit model weights, generated images, databases, `.env` files, keys, or tokens.

## Operating policy

- Source and configuration belong in Git.
- Model weights belong under `E:\models` or a Docker volume.
- Generated images and private documents belong under `E:\data` or another backed-up data path.
- Record model provenance, license, quantization, checksum, context length, and intended use.
