Private GPT, prompting, local-model, image-generation, and Docker operations hub for this workstation.

## Requirements

- Windows 11 with WSL2 Ubuntu
- Git, Node.js 20+, and npm
- Docker Desktop with WSL integration
- NVIDIA driver and Docker GPU support

This npm project has no runtime dependencies; npm is a portable task runner.

## Commands

```powershell
npm install
npm run check
npm run stack:doctor
npm run media -- init
npm run stack:config
npm run models -- list
npm run models -- sync-localai
npm run stack -- up inference
npm run stack -- backend
npm run stack -- up rag
npm run stack -- up comfy
npm run models -- inventory
npm run media -- status
npm run repos:status
npm run repos:fetch
npm run inventory
```

The stack profiles are `inference`, `rag`, `media`, and `comfy`; the Comfy profile runs both the GPU backend and frontend proxy. Storage roots and fork contexts are machine-readable in `config/`.

`repos:fetch` refreshes remote references without changing working files. `repos:update` fetches both remotes and only fast-forwards from the upstream default branch. It refuses dirty or detached worktrees and never resets, rebases, force-pushes, or deletes work.

Current warning: PrivateGPT and Stable Diffusion appear dirty across many files. Review line endings and preserve intentional changes before `npm run repos:update`.

## GitHub setup

This repository tracks `origin/main` as `likwidmack/forkedAI`; the managed forks belong to `tamaramack`. `repos:status` is read-only, `repos:fetch` only refreshes refs, and `repos:update` permits fast-forward-only updates after refusing dirty or detached worktrees.

Authentication tokens are account-scoped secrets and must never be committed, printed, or copied between account configurations. Never commit model weights, generated media, databases, `.env` files, keys, or tokens.

## Operating policy

- Source and configuration belong in Git.
- Model weights belong under `E:\models` or a Docker volume.
- Generated images and private documents belong under `E:\data` or another backed-up data path.
- Record model provenance, license, quantization, checksum, context length, and intended use.
